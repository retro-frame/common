2. DBAC
===============================================================================

32 bit pattern (length=19):

  4word-4word-4word-4word

  The bits for the words are taken from a 32 bit big endian value from highest
  to lowest bits (e.g. 0x01234567 ==> 0x01 bits for first word, 0x23 bits for
  second word and so on).

  0x01B:  5word-4word-5word-5word-4word-4word-4word
  0x01C:  5word-5word-4word-4word-4word-4word-5word
  0x01D:  5word-5word-4word-4word-4word-5word-4word
  0x01E:  5word-5word-4word-4word-5word-4word-4word
  0x01F:  5word-5word-4word-5word-4word-4word-4word

  The bits for the pattern are taken from a 64 bit big endian value from
  highest bits. The bits for the words are taken from the value in order of
  the pattern from highest to lowest bits.

  Example: 0x0F1E2D3C4B5A6789

  ==> Pattern 0x001: 4word-4word-4word-5word-5word-4word-5word
  ==> 4word 0x0E3: TRIO
  ==> 4word 0x0C5: SIGN
  ==> 4word 0x0A7: PALM
  ==> 5word 0x112: MICRO
  ==> 5word 0x1AD: STEAM
  ==> 4word 0x033: DIVE
  ==> 5word 0x189: SHARP

  TRIO-SIGN-PALM-MICRO-STEAM-DIVE-SHARP
